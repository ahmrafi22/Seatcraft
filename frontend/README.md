# SeatCraft web

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Motion · react-icons

Operator console for the SeatCraft API. Work in progress.

```bash
npm install
npm run dev
```

The API is expected at `http://localhost:5199`. Point it elsewhere with
`SEATCRAFT_API_ORIGIN`:

```bash
SEATCRAFT_API_ORIGIN=https://seatcraft-api.example.com npm run dev
```
